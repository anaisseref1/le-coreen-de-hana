Module 15 · Penser, paraphraser et improviser

Décrire un objet sans connaître son nom

🎯 OBJECTIFS

✔ construire une description progressive ;

✔ utiliser taille, forme, matière, emplacement et fonction ;

✔ poser des questions de clarification.

🟩 OUTILS

크다 / 작다 → grand / petit
길다 / 짧다 → long / court
둥글다 → rond
네모나다 → carré / rectangulaire
무겁다 / 가볍다 → lourd / léger
안에 / 위에 / 옆에 → dedans / dessus / à côté
비슷하다 → être similaire
생기다 → avoir une apparence

💙 DESCRIPTION EN ENTONNOIR

Ne donne pas vingt détails au hasard.

Commence large :

물건이에요.
→ C'est un objet.

Puis :

주방에서 써요.
→ On l'utilise dans la cuisine.

Puis :

음식을 자를 때 써요.
→ On l'utilise pour couper les aliments.

Réponse probable :

칼?
→ Un couteau ?

💬 DIALOGUE

🌸 Ana : 이름이 생각 안 나는데... 작은 기계예요. 주방에서 쓰고,
과일이나 채소를 갈 때 써요.
💙 Min-su : 믹서기요?
🌸 Ana : 네! 믹서기!

🌸 DEMANDER LE NOM

이거 한국어로 뭐라고 해요?
→ Comment appelle-t-on ça en coréen ?
이거 이름이 뭐예요?
→ Comment ça s'appelle ?

🧩 MISSION — OBJET MYSTÈRE

Décris cinq objets en donnant maximum quatre indices.

lorsque le dictionnaire mental est vide. »
