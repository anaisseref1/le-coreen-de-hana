Chapitre 126 · 👥

Module 11 · Développer ses idées

Participer à une discussion plus longue

🎯 OBJECTIFS

✔ prendre la parole ; ✔ rebondir ; ✔ demander une précision ; ✔ être
d'accord ou nuancer ; ✔ donner raison + exemple + contraste.

🟩 OUTILS

저도 그렇게 생각해요. → Je pense pareil.
저는 조금 다르게 생각해요. → Je vois les choses différemment.
그건 맞는데... → C'est vrai, mais...
왜 그렇게 생각해요? → Pourquoi ?
예를 들면요? → Par exemple ?
제 경험으로는... → D'après mon expérience...
아까 말한 것처럼... → Comme dit tout à l'heure...

💬 DISCUSSION

💙 Min-su : 저는 혼자 여행하면 좀 심심할 것 같아요.
💚 Ji-soo : 진짜? 나는 오히려 자유로워서 좋은데.
🌸 Ana : 나도 자유로운 건 좋은 것 같아. 그런데 가끔 혼자 해결해야
하는 일이 많잖아.
💙 Min-su : 아나 씨는 혼자 여행해 본 적 있어요?
🌸 Ana : 네, 있어요. 제 경험으로는 처음에는 조금 긴장되지만 익숙해지면 훨씬 편해져요.
💚 Ji-soo : 그러면 혼자 여행하는 걸 더 좋아해?
🌸 Ana : 꼭 그런 건 아니야. 여행에 따라 다른 것 같아.

🧠 IMPORTANT

Une discussion alterne : → réaction courte → question → développement
→ écoute → rebond
