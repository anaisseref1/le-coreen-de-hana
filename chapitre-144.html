Chapitre 144 · 💬

Module 13 · Médias et numérique

Comprendre les commentaires coréens

🌸 Illustration d'ouverture

Sous une vidéo :

너무 귀여워요ㅠㅠ
이 부분 진짜 웃김ㅋㅋㅋ
나만 그런 것 같았는데
인정
완전 공감

Ana connaît 귀여워요.

Le reste ressemble à une réunion secrète. 😭

🎯 OBJECTIFS

✔ reconnaître le style conversationnel écrit ;

✔ comprendre les phrases tronquées ;

✔ repérer accord, émotion et réaction ;

✔ ne pas copier automatiquement un registre familier.

🟩 EXPRESSIONS

공감 → je compatis / je m'y reconnais
완전 공감 → tellement vrai / je m'y reconnais totalement
인정 → j'avoue / validé / je reconnais
웃김 → c'est drôle
귀여움 → le côté mignon / trop mignon selon contexte
나만 그런 것 같았어 → j’avais l’impression d’être le/la seul(e)
맞아요 → exactement
저도요 → moi aussi

💙 POURQUOI 웃김 ?

Dans certains usages numériques, on rencontre des formes nominalisées ou
condensées comme :

웃기다 → 웃김

Elles sont courantes dans certains commentaires, mais **ne remplacent
pas partout les phrases standard**.

💬 MINI-FIL

A: 이 부분 진짜 웃김ㅋㅋ
B: 인정ㅋㅋㅋ
C: 나만 계속 본 거 아니지?
D: 저도요ㅠㅠ

Compréhension :

A trouve le passage très drôle.
B approuve.
C demande en plaisantant s'il/elle est la seule personne à l'avoir
regardé en boucle.
D : « Moi aussi 😭 ».

🟨 REGISTRE

Comprendre ≠ utiliser immédiatement.

Observe d'abord : > qui écrit ?
> à qui ?
> sur quelle plateforme ?
> quel ton ?

🧩 MISSION

Classe 15 commentaires : > compliment / accord / rire / surprise /
critique / question / émotion.

🌟 PHRASE

**« Sur Internet, une réaction de deux syllabes peut parfois remplacer
une phrase entière. »**
