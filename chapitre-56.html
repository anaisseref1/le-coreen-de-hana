Chapitre 56 · 🎧

질문이 있는데요…

Comprendre et utiliser -는데 / -은데 / -ㄴ데

🌸 Illustration d’ouverture

💚 Ji-soo :
질문이 있는데요…
→ J’ai une question…

💙 Min-su :
오늘 좀 바쁜데…
→ Aujourd’hui, je suis un peu occupé…

Ana reconnaît les mots mais remarque une terminaison récurrente : -는데.

Parfois elle crée un contraste, parfois elle prépare une question, et parfois la phrase reste ouverte.

Idée centrale : -는데 pose un contexte et crée un lien avec ce qui vient ensuite.

🎯 Objectif

✅ reconnaître -는데 / -은데 / -ㄴ데 à l’oral

✅ comprendre qu’il n’existe pas une seule traduction française

✅ utiliser -는데 avec les verbes d’action

✅ utiliser -(으)ㄴ데 avec les verbes descriptifs

✅ utiliser 인데 avec les noms

✅ préparer une question / demande

✅ exprimer un contraste léger

✅ comprendre une phrase laissée ouverte

🟩 Vocabulaire

질문 → question

바쁘다 → être occupé

피곤하다 → être fatigué

어렵다 → être difficile

쉽다 → être facile

맛있다 → être délicieux

비싸다 → être cher

싸다 → être bon marché

조용하다 → être calme

학생 → étudiant

회사원 → employé de bureau

부탁 → faveur / demande

💙 Une idée plutôt qu’une traduction

Ne retiens pas simplement -는데 = mais.

« Voilà la situation… maintenant, écoute la suite. »

🌸 1 — Donner un contexte

지금 좀 바쁜데…

→ Là, je suis un peu occupé…

La phrase peut rester ouverte parce que l’interlocuteur comprend qu’une suite est implicite.

지금 좀 바쁜데 나중에 전화할게요.

→ Là, je suis un peu occupé, donc je t’appellerai plus tard.

🌸 2 — Préparer une question ou une demande

질문이 있는데요… → J’ai une question…

질문이 있는데요, 이건 무슨 뜻이에요? → J’ai une question : qu’est-ce que ça veut dire ?

문제가 있는데요… → J’ai un problème…

🌸 3 — Contraste léger

한국에 가고 싶은데 돈이 없어요.

→ J’aimerais aller en Corée, mais je n’ai pas d’argent.

가고 싶은데 시간이 없어요. → Je veux y aller, mais je n’ai pas le temps.

사고 싶은데 너무 비싸요. → Je veux l’acheter, mais c’est trop cher.

🧩 Formation — verbes d’action

radical + -는데

가다 → 가는데

먹다 → 먹는데

공부하다 → 공부하는데

일하다 → 일하는데

Pour les verbes en 하다 : 하다 → 하는데.

💙 Formation — verbes descriptifs

voyelle → -ㄴ데

바쁘다 → 바쁜데

예쁘다 → 예쁜데

consonne → -은데

작다 → 작은데

좋다 → 좋은데

⚠️ Quelques formes particulières à reconnaître

있다 → 있는데

없다 → 없는데

맛있다 → 맛있는데

어렵다 → 어려운데

쉽다 → 쉬운데

Ne cherche pas encore à mémoriser toutes les règles d’irréguliers : retiens ces formes fréquentes comme des blocs.

🌸 Exemples descriptifs

이 카페는 조용한데 사람이 많아요. → Ce café est calme, mais il y a beaucoup de monde.

이 가방은 예쁜데 너무 비싸요. → Ce sac est joli, mais il est trop cher.

오늘 피곤한데 공부해야 해요. → Aujourd’hui je suis fatiguée, mais je dois étudier.

💙 Formation — noms

nom + 인데

학생 → 학생인데

회사원 → 회사원인데

저는 회사원인데 한국어를 공부해요.

→ Je suis employée de bureau et j’étudie le coréen.

🧠 Carte mentale

Verbe d’action → -는데

Verbe descriptif → -(으)ㄴ데

Nom → 인데

🟨 Pas une traduction fixe

질문이 있는데요… → J’ai une question…

한국에 가고 싶은데 돈이 없어요. → …mais je n’ai pas d’argent.

지금 좀 바쁜데… → Là, je suis un peu occupé…

Le contexte décide de la traduction.

💬 Dialogue

🌸 민수 씨, 질문이 있는데요…

💙 네, 뭐예요?

🌸 이 표현을 아는데 잘 사용할 수 없어요.
→ Je connais cette expression, mais je n’arrive pas à bien l’utiliser.

💙 괜찮아요. 처음에는 많이 들어야 해요.

🌸 그런데 왜 이렇게 자주 써요?

💙 상황을 자연스럽게 연결해요.
→ Ça relie naturellement le contexte.

💚 이제 이해해요?

🌸 조금요!

💙 -는데요

질문이 있는데… → plus familier / neutre selon contexte

질문이 있는데요… → poli

Le 요 rend la forme polie, et l’ensemble peut aussi porter une nuance de douceur, d’attente ou de réaction selon l’intonation.

🌸 L’intonation compte

이거 맛있는데요! → Oh, mais c’est vraiment bon !

맛있는데요… peut, selon le ton, suggérer surprise, commentaire, désaccord léger ou attente d’une réaction.

💙 Introduire doucement

질문이 있는데요… → J’ai une question…

부탁이 있는데요… → J’ai une faveur à demander…

문제가 있는데요… → J’ai un problème…

💙 Le bon réflexe

Quand tu entends -는데 / -은데 / -ㄴ데, pense : « cette information sert de contexte ; qu’est-ce qui vient ensuite ? »

🌸 네, 뭐예요?

💚 내일 좀 바쁜데 이것 좀 해 줄 수 있어요?

🌸 네, 할 수 있어요.

💙 저도 도와주고 싶은데 내일 약속이 있어요.

🌸 괜찮아요. 제가 할게요.

📖 Compréhension — reconnais la fonction

질문이 있는데요… → question / demande

오늘은 좀 피곤한데… → contexte / phrase ouverte

이 가방은 예쁜데 너무 비싸요. → contraste

저는 회사원인데 한국어를 공부해요. → contexte / liaison

이거 맛있는데요! → réaction / nuance

💚 Conseil de Ji-soo

Ne cherche pas d’abord « quelle est la traduction de -는데 ? ».

Demande-toi plutôt : « Pourquoi le locuteur l’utilise ici ? »
