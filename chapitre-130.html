Chapitre 130 · 📢

Module 12 · Rapporter les paroles et les points de vue

Rapporter un ordre ou une demande

🎯 OBJECTIFS

✔ utiliser -(으)라고 하다 ; ✔ distinguer déclaration et consigne ; ✔
rapporter une demande simple.

💙 CONSIGNE

앉으세요 → 앉으라고 했어요.
→ Il/elle a dit de s'asseoir.
기다리세요 → 기다리라고 했어요.
→ Il/elle a dit d'attendre.

Après consonne : 먹다 → 먹으라고 하다
Après voyelle : 가다 → 가라고 하다

💬 DIALOGUE

🌸 Ana : 의사 선생님이 뭐라고 했어?
💚 Ji-soo : 오늘은 푹 쉬라고 했어. 물을 많이 마시라고 했어.
🌸 Ana : 약도 먹으라고 했어?
💚 Ji-soo : 응. 식후에 먹으라고 했어.

😈 COMPARONS

먹는다고 했어요. → Il/elle a dit qu'il/elle mangeait.
먹으라고 했어요. → Il/elle a dit de manger.

✍️ EXERCICES

Rapporte : 빨리 오세요 / 문을 닫으세요 / 이 약을 드세요 / 여기에서
기다리세요.

la personne voulait que l'autre fasse. »
