Module 14 · Nuances culturelles et relationnelles

Comprendre 눈치 : lire la situation sans lire dans les pensées

🌸 Illustration d'ouverture

Ana est avec Ji-soo, Min-su et plusieurs amis.

Tout le monde discute.

Soudain, une personne regarde l'heure.

Une autre commence à ranger ses affaires.

La conversation ralentit.

Ana, elle, lance joyeusement :

🌸 Ana : > 우리 다른 카페도 갈까요?

On va dans un autre café ?

Silence.

Ji-soo sourit.

Plus tard :

💚 Ji-soo : > 아까 다들 집에 갈 것 같았어.

Ana :

...Personne ne l'a dit. 😭

Bienvenue dans 눈치.

🎯 OBJECTIFS

✔ comprendre le sens général de 눈치 ;

✔ observer plusieurs indices avant d'interpréter ;

✔ distinguer information explicite et lecture de situation ;

✔ éviter de présenter une interprétation comme une certitude ;

✔ demander confirmation quand nécessaire.

💙 눈치 N'EST PAS DE LA TÉLÉPATHIE

Une interprétation culturelle est une hypothèse contextualisée, jamais un diagnostic sur “les Coréens”.

Observer les indices sociaux existe dans toutes les cultures ; 눈치 donne simplement un cadre coréen très utile pour en parler.

Avoir du 눈치 ne signifie pas :

« savoir exactement ce que tout le monde pense ».

Il s'agit plutôt de remarquer :

mots + ton + silence + réactions + contexte + relation.

Puis de construire une hypothèse raisonnable.

🌸 EXPRESSIONS

눈치를 보다
→ observer les réactions / tâter le terrain.
눈치가 빠르다
→ comprendre rapidement les indices sociaux.
눈치가 없다
→ manquer les indices sociaux / ne pas sentir la situation.

⚠️ Cette dernière expression peut être critique. On ne la lance pas à
n'importe qui comme une étiquette.

💬 DIALOGUE

🌸 Ana : 아까 내가 뭐 잘못했어?
💚 Ji-soo : 잘못한 건 아닌데, 다들 좀 피곤해 보였어.
🌸 Ana : 아무도 집에 간다고 안 했잖아.
💚 Ji-soo : 맞아. 그냥 분위기를 보니까 그런 것 같았어.
🌸 Ana : 아... 다음에는 좀 더 잘 봐야 해.

🟨 RÈGLE DU CHAPITRE

Ne pense pas :

« Les Coréens veulent toujours dire X quand ils font Y. »

Pense :

« Dans cette situation, plusieurs indices suggèrent peut-être X. »

✍️ EXERCICE

Pour chaque scène, sépare :

fait observable / interprétation possible.

Exemple :

Fait : Min-su regarde plusieurs fois l'heure.
Interprétation possible : il souhaite peut-être partir.

🧩 MISSION --- DÉTECTIVE, PAS VOYANTE 🔎

Observe une scène.

Donne : 1. trois indices observables ; 2. deux interprétations possibles
; 3. une façon de vérifier.

🌟 PHRASE

**« Lire une situation, ce n'est pas deviner les pensées des autres :
c'est remarquer les indices sans oublier qu'on peut se tromper. »**
