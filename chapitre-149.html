Chapitre 149 · 🔔

Module 13 · Médias et numérique

Comprendre les notifications et messages automatiques

🌸 Illustration d'ouverture

Le téléphone d'Ana affiche :

배송이 시작되었습니다.

Puis :

결제가 완료되었습니다.

Puis :

비밀번호를 다시 확인해 주세요.

Ana n'a parlé à personne, mais le coréen formel vient de revenir. 😭

🎯 OBJECTIFS

✔ comprendre les notifications courantes ;

✔ reconnaître -되었습니다 comme forme formelle fréquente dans les notifications
;

✔ identifier l'action attendue ;

✔ reconnaître confirmation, erreur, livraison et sécurité.

🟩 VOCABULAIRE

결제 → paiement
완료 → terminé
배송 → livraison
주문 → commande
확인 → vérification
비밀번호 → mot de passe
인증 → authentification
오류 → erreur
실패 → échec
취소 → annulation
변경 → modification
저장 → sauvegarde

💙 FORMULES — À RECONNAÎTRE D’ABORD

결제가 완료되었습니다.
→ Le paiement a été effectué.
주문이 취소되었습니다.
→ La commande a été annulée.
다시 시도해 주세요.
→ Veuillez réessayer.
비밀번호를 확인해 주세요.
→ Veuillez vérifier votre mot de passe.

🟨 STRATÉGIE

Une notification répond souvent à deux questions :

Qu'est-ce qui vient de se passer ?
Dois-je faire quelque chose ?

✍️ EXERCICE

Classe : → information / confirmation / erreur / action requise /
avertissement.

🧩 MISSION — TON TÉLÉPHONE EST EN CORÉEN

Interprète dix notifications sans traduire mot à mot.

🌟 PHRASE

« Dans une notification, cherche d'abord l'état du système et
l'action attendue. »
