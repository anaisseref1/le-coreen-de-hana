Participer à une longue conversation

🎯 OBJECTIFS

✔ rester dans une conversation pendant 20 minutes ;

✔ suivre plusieurs changements de sujet ;

✔ relancer ;

✔ raconter ;

✔ réagir ;

✔ demander une clarification ;

✔ revenir après avoir perdu le fil.

😈 NOUVELLE CONTRAINTE

L'autre personne n'est plus un examinateur.

Elle :

interrompt parfois ;
change de sujet ;
raconte trop longtemps ;
demande des détails ;
n'est pas toujours d'accord.

Comme une vraie personne.

🧩 MISSION --- 20 MINUTES

Objectifs secrets :

poser au moins trois questions de suivi ;
raconter une anecdote ;
exprimer un désaccord ;
réparer un blocage ;
changer naturellement de sujet.

🌟 PHRASE
