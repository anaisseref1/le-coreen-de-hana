Chapitre 121 · 💡

Module 11 · Développer ses idées

Donner un exemple pour illustrer une idée

🎯 OBJECTIFS

✔ utiliser 예를 들면 / 예를 들어 ; ✔ préciser avec 특히 ; ✔ rendre une
affirmation concrète.

💙 PAR EXEMPLE

서울은 정말 편리해요. 예를 들면 지하철로 거의 어디든 갈 수 있어요.
→ Séoul est vraiment pratique. Par exemple, on peut aller presque
partout en métro.

🌸 특히

한국 음식 중에서 특히 비빔밥을 좋아해요.
→ Parmi les plats coréens, j'aime particulièrement le bibimbap.

💬 DIALOGUE

💚 Ji-soo : 한국 생활에서 편한 점이 뭐야?
🌸 Ana : 대중교통이 편한 것 같아.
💚 Ji-soo : 구체적으로?
🌸 Ana : 예를 들어 지하철이 늦게까지 있고, 버스도 많잖아. 특히
서울에서는 차가 없어도 여기저기 갈 수 있어.

🧩 MISSION --- PROUVE-LE

Développe : « C'est pratique », « C'est difficile », « J'aime cette
ville » avec un exemple concret.

🌟 PHRASE

**« Un exemple transforme une idée abstraite en quelque chose que
l'autre peut voir. »**
