Chapitre 67 · 💭

제 생각에는… / 것 같아요.

Nuancer son opinion : 생각해요 ou 것 같아요 ?

🌸 Illustration d’ouverture

💚 이 영화 어땠어?

🌸 재미있었어.

Ana veut maintenant dire quelque chose de plus précis : « Je pense que le film était un peu long. »

Elle connaît déjà 생각하다 et elle a déjà rencontré -(으)ㄹ 것 같아요.

Aujourd’hui, on ne découvre pas simplement “je pense que”. On apprend à choisir la nuance.

🎯 Objectif

✅ annoncer son avis avec 제 생각에는…

✅ réviser les formes de 생각해요

✅ comprendre 것 같아요 comme impression / opinion prudente

✅ former 것 같아요 au présent avec descriptifs et verbes d’action

✅ revoir -(으)ㄹ 것 같아요 pour l’estimation future

✅ choisir la nuance adaptée

💙 제 생각에는… — À mon avis…

제 생각에는 이 영화가 조금 길어요.

제 생각에는 이 식당이 좋아요.

제 생각에는 첫 번째 영화가 더 재미있어요.

제 = mon / ma, forme possessive de 저.

💙 Rappel — 생각해요

Ana connaît déjà les formes permettant de relier une idée à 생각해요.

Descriptif → -다고 생각해요

Action → -ㄴ/는다고 생각해요

Nom → (이)라고 생각해요

Exemples :

이 영화가 재미있다고 생각해요.

민수 씨가 자주 운동한다고 생각해요.

좋은 방법이라고 생각해요.

🎯 Ici, le but n’est pas de refaire le discours rapporté : on compare surtout la nuance avec 것 같아요.

💙 것 같아요 — Il me semble que…

Selon le contexte :

→ je pense que…

→ j’ai l’impression que…

→ il me semble que…

→ on dirait que…

Cette structure est souvent plus prudente et moins catégorique.

🌸 Opinion vs impression

이 영화가 길다고 생각해요.
→ Je pense que ce film est long.

이 영화가 조금 긴 것 같아요.
→ J’ai l’impression qu’il est un peu long.

생각해요 = voilà ce que je pense.
것 같아요 = voilà l’impression que j’ai.

💙 Formation — descriptifs au présent

-(으)ㄴ 것 같아요

좋다 → 좋은 것 같아요.

작다 → 작은 것 같아요.

비싸다 → 비싼 것 같아요.

재미있다 → 재미있는 것 같아요.

💙 Formation — verbes d’action au présent

-는 것 같아요

먹다 → 먹는 것 같아요.

공부하다 → 공부하는 것 같아요.

기다리다 → 기다리는 것 같아요.

💙 Estimation future — révision

-(으)ㄹ 것 같아요

비가 오다 → 비가 올 것 같아요.

늦다 → 늦을 것 같아요.

Cette forme est déjà connue depuis le chapitre 52. Ici, elle rejoint la logique générale de 것 같아요.

🧠 Carte mentale

제 생각에는… → j’annonce mon avis

생각해요 → jugement / opinion formulée

것 같아요 → impression / prudence

-(으)ㄹ 것 같아요 → estimation future

💬 Dialogue

💚 아나야, 어제 영화 어땠어?

🌸 제 생각에는 이야기가 재미있었어.

💙 나도 그렇게 생각해.

🌸 근데 영화가 조금 긴 것 같아.

💚 진짜? 나는 괜찮았는데.

🌸 제 생각에는 배우들도 정말 좋았어.

💙 맞아. 특히 마지막 장면이 좋았어.

🌸 응. 근데 두 번째 영화가 첫 번째보다 더 좋은 것 같아.

💙 Quelle forme choisir ?

Opinion annoncée → 제 생각에는 이게 더 좋아요.

Jugement → 이 방법이 좋다고 생각해요.

Opinion prudente → 이 방법이 더 좋은 것 같아요.

Observation → 민수 씨가 피곤한 것 같아요.

🎧 Audio 66.1 — compare

제 생각에는 좋아요. · 좋다고 생각해요. · 좋은 것 같아요.

🎧 Audio 66.2 — opinion ou impression ?

민수 씨가 피곤한 것 같아요. · 제 생각에는 이 영화가 더 재미있어요. · 비가 올 것 같아요. · 이 방법이 좋다고 생각해요.

📖 Compréhension — compare les nuances

제 생각에는 이 영화가 좋아요. → avis annoncé

이 영화가 좋다고 생각해요. → opinion formulée

이 영화가 좋은 것 같아요. → impression plus prudente

민수 씨가 피곤한 것 같아요. → impression d’après ce qu’on observe

🎯 Mission — une opinion, trois nuances

Choisis un film, une ville, un plat ou une activité et exprime :

① avis direct

② 제 생각에는…

③ impression avec 것 같아요

💚 Conseil de Min-su

번역보다 느낌이 중요해요.

→ La nuance est plus importante que la traduction.

🌟 Phrase du chapitre

« Donner son opinion, ce n’est pas seulement choisir ses mots : c’est aussi choisir la nuance qu’on veut leur donner. »
