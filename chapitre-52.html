Chapitre 52 · 📱

도착하면 연락할게요.

Téléphoner et envoyer un message

🌸 Illustration d’ouverture

Ana doit retrouver Ji-soo dans un café, mais le métro est retardé.

Elle doit simplement prévenir qu’elle va être en retard et dire ce qu’elle fera ensuite.

🎯 Objectif

✅ dire où tu es

✅ dire que tu vas être en retard

✅ prévenir quelqu’un

✅ utiliser -(으)ㄹ게요 pour une décision / promesse liée à l’interlocuteur

✅ réviser -(으)ㄹ 것 같아요 pour une estimation

✅ téléphoner et envoyer un message simple

🟩 Vocabulaire utile

전화하다 → téléphoner

메시지를 보내다 → envoyer un message

연락하다 → contacter / donner des nouvelles

기다리다 → attendre

늦다 → être en retard

도착하다 → arriver

출발하다 → partir

곧 → bientôt

거의 → presque

나중에 → plus tard

통화하다 → parler au téléphone

배터리 → batterie

💬 Dialogue

🌸 지수 씨, 지금 어디예요?
→ Ji-soo, tu es où ?

💚 카페에 있어요. 아나 씨는요?
→ Je suis au café. Et toi ?

🌸 아직 지하철이에요.
→ Je suis encore dans le métro.

💚 곧 도착해요?
→ Tu arrives bientôt ?

🌸 조금 늦을 것 같아요.
→ Je pense que je vais être un peu en retard.

💚 괜찮아요. 천천히 와요.
→ Pas de problème. Viens tranquillement.

🌸 미안해요. 도착하면 연락할게요.
→ Désolée. Je te contacterai quand j’arriverai.

💚 네, 알겠어요. 기다릴게요.
→ D’accord. Je vais t’attendre.

🌸 거의 도착했어요!
→ Je suis presque arrivée !

💚 카페 앞에서 기다리고 있어요.
→ Je t’attends devant le café.

🌸 네, 곧 갈게요!
→ Oui, j’arrive bientôt !

💙 Grammaire — -(으)ㄹ게요

Cette structure exprime souvent une décision, une intention ou une promesse du locuteur, en lien avec la personne à qui l’on parle.

verbe + -(으)ㄹ게요

연락할게요. → Je te contacterai.

전화할게요. → Je t’appellerai.

기다릴게요. → Je vais t’attendre.

메시지 보낼게요. → Je t’enverrai un message.

🧩 Formation

가다 → 갈게요
먹다 → 먹을게요
살다 → 살게요
하다 → 할게요

🟨 -(으)ㄹ 거예요 vs -(으)ㄹ게요

저녁에 전화할 거예요. → Je vais téléphoner ce soir. Projet général.

저녁에 전화할게요. → Je t’appellerai ce soir. Décision / promesse envers l’autre.

♻️ Rappel — -(으)ㄹ 것 같아요

Tu connais déjà cette structure pour exprimer une estimation.

조금 늦을 것 같아요. → Je pense que je vais être un peu en retard.

비가 올 것 같아요. → Je pense qu’il va pleuvoir.

💙 Où es-tu ?

지금 어디예요? → Tu es où maintenant ?

집에 있어요. → Je suis à la maison.

카페에 있어요. → Je suis au café.

지하철에 있어요. → Je suis dans le métro.

거의 도착했어요. → Je suis presque arrivée.

🌸 도착하면 연락할게요

도착하면 → quand / si j’arrive

연락할게요 → je te contacterai

도착하면 연락할게요. → Je te contacterai quand j’arriverai.

📞 Téléphoner

여보세요? → Allô ?

지금 전화해도 돼요? → Est-ce que je peux appeler maintenant ?

지금 통화할 수 있어요? → Tu peux parler au téléphone maintenant ?

지금은 통화할 수 없어요. → Je ne peux pas parler maintenant.

나중에 전화할게요. → Je t’appellerai plus tard.

💬 Messages utiles

메시지 보내 주세요. → Envoie-moi un message.

메시지를 못 봤어요. → Je n’ai pas vu ton message.

답장을 못 했어요. → Je n’ai pas pu répondre.

도착하면 메시지 보내 주세요. → Envoie-moi un message quand tu arrives.

🧠 Carte mentale — prévenir d’un retard

① 지금 어디예요? → où ?
② 아직 지하철이에요. → où je suis
③ 조금 늦을 것 같아요. → estimation
④ 미안해요. → excuse
⑤ 도착하면 연락할게요. → ce que je promets de faire

📖 Compréhension

💚 지수 : 아나 씨, 지금 어디예요?

🌸 아나 : 아직 버스에 있어요.

💚 지수 : 몇 시에 도착할 것 같아요?

🌸 아나 : 아마 세 시 십 분쯤 도착할 것 같아요.

💚 지수 : 괜찮아요. 카페에서 기다릴게요.

🌸 아나 : 미안해요. 도착하면 메시지 보낼게요.

💚 지수 : 네, 천천히 와요.
