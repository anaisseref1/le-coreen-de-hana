Module 14 · Nuances culturelles et relationnelles

Exprimer un désaccord sans casser la relation

🎯 OBJECTIFS

✔ reconnaître un désaccord adouci ;

✔ utiliser accord partiel + réserve ;

✔ exprimer une autre perspective ;

✔ différencier contenu du désaccord et ton relationnel.

💙 FORMES UTILES

맞아요. 그런데...
→ C'est vrai. Mais...
그럴 수도 있는데...
→ Ça peut être le cas, mais...
저는 조금 다르게 생각해요.
→ Je vois les choses un peu différemment.
제 생각에는...
→ À mon avis...
꼭 그런 건 아닌 것 같아요.
→ Je ne pense pas que ce soit forcément toujours comme ça.

💬 DIALOGUE

💙 Min-su : 여행은 계획 없이 가는 게 제일 재미있는 것 같아요.
🌸 Ana : 그럴 수도 있는데 저는 조금 다르게 생각해요. 중요한 건 미리
예약하는 게 편하거든요.
💙 Min-su : 아, 그것도 맞네요.

🌸 DÉSACCORD ≠ CONFLIT

Une phrase très directe peut être acceptable dans certaines relations et
situations.

Le but n'est pas :

« toujours parler indirectement ».

Le but est :

choisir un degré de franchise adapté.

🧩 MISSION — TROIS VERSIONS

Exprime le même désaccord : 1. avec une amie proche ; 2. avec une
nouvelle connaissance ; 3. dans une discussion plus formelle.

🌟 PHRASE

« Nuancer un désaccord ne change pas nécessairement ton opinion ;
cela change la manière dont tu la places dans la relation. »
