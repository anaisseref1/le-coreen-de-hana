Module 14 · Nuances culturelles et relationnelles

Réparer un malentendu culturel ou relationnel

🎯 OBJECTIFS

✔ vérifier une intention ;

✔ expliquer ce qu'on voulait dire ;

✔ s'excuser sans dramatiser ;

✔ demander comment une phrase a été comprise ;

✔ reformuler.

🟩 EXPRESSIONS

제가 잘못 이해한 것 같아요.
→ Je crois que j'ai mal compris.
그런 뜻으로 말한 게 아니에요.
→ Ce n'est pas dans ce sens que je l'ai dit.
혹시 기분 나빴어요?
→ Est-ce que ça t'a peut-être vexé(e) ?
제가 너무 직접적으로 말했어요?
→ Est-ce que j'ai parlé trop directement ?
어떻게 들렸어요?
→ Comment ça a sonné / comment tu l'as compris ?
다시 말하면...
→ Pour reformuler...

💬 DIALOGUE

🌸 Ana : 아까 제가 한 말 혹시 기분 나빴어요?
👤 Connaissance : 조금 놀랐어요.
🌸 Ana : 죄송해요. 그런 뜻으로 말한 게 아니었어요. 제가 너무 직접적으로 말한 것 같아요.
👤 Connaissance : 괜찮아요. 지금 설명해 줘서 이해했어요.

💙 UNE ERREUR N'EST PAS LA FIN DE LA CONVERSATION

Compétence avancée :

ne jamais se tromper ❌

Compétence avancée :

remarquer → vérifier → expliquer → réparer ✅

🧩 MISSION — RÉPARATION

Reçois quatre malentendus.

Pour chacun : 1. vérifie ; 2. reformule ; 3. adapte ton registre ; 4.
continue la conversation.

🌟 PHRASE

« Une vraie compétence relationnelle ne consiste pas à éviter tous
les malentendus, mais à savoir quoi faire lorsqu'ils arrivent. »
