Chapitre 142 · 🎬

Module 13 · Médias et numérique

Lire des sous-titres sans traduire chaque mot

🌸 Illustration d'ouverture

Ana active les sous-titres coréens.

Bonne idée.

Puis une ligne apparaît pendant deux secondes :

오늘은 생각보다 사람이 별로 없어서 좀 여유롭게 볼 수 있을 것 같아요.

Ana : REVIENS. 😭

🎯 OBJECTIFS

✔ lire par groupes de sens ;

✔ repérer la fin de phrase ;

✔ identifier les informations prioritaires ;

✔ comprendre sans fabriquer immédiatement une traduction française
parfaite.

💙 NE LIS PAS MOT PAR MOT

Découpe :

오늘은 / 생각보다 / 사람이 별로 없어서 / 좀 여유롭게 / 볼 수 있을 것
같아요.

Puis reconstruis l'idée :

aujourd'hui / moins de monde que prévu / donc / tranquillement / je
pense pouvoir regarder.

Tu n'as pas besoin de produire immédiatement :

« Aujourd'hui, puisqu'il y a moins de personnes que ce à quoi je
m'attendais... »

😭 La vidéo est déjà partie.

🌸 PRIORITÉ VISUELLE

Quand un sous-titre apparaît, cherche :

nom important + verbe final + connecteur + négation éventuelle

🧠 EXEMPLE

이 카페는 예뻐요. 그런데 커피가 생각보다 비싸요.

Repère :

카페 / 예쁘다 / 그런데 / 커피 / 비싸다

Idée :

café joli mais café assez cher.

✍️ EXERCICE — 3 SECONDES

Lis plusieurs lignes pendant un temps limité puis note seulement l'idée
principale.

🧩 MISSION

Regarde un extrait avec sous-titres coréens.

Premier passage : ne lis que les fins de phrase.

Deuxième : ajoute noms et connecteurs.

Troisième : reconstruis l'ensemble.

🌟 PHRASE

« Les sous-titres sont une aide à l'écoute, pas un texte à traduire
sous pression. »
