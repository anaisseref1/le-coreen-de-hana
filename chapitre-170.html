Module 15 · Penser, paraphraser et improviser

Contourner un mot qu’on ne connaît pas

🌸 Illustration d'ouverture

Ana veut demander un « tire-bouchon ».

Elle ne connaît évidemment pas le mot.

Son ancien réflexe :

téléphone → dictionnaire.

Ji-soo l'arrête.

💚 Ji-soo : → 설명해 봐.

Essaie de l'expliquer.

😈

🎯 OBJECTIFS

✔ continuer sans connaître un nom ;

✔ utiliser fonction, apparence, lieu et catégorie ;

✔ employer -는 것 / 물건 / 사람 / 곳 ;

✔ demander le mot après avoir tenté de l'expliquer.

💙 LES QUATRE PORTES DE SORTIE

Quand un mot manque, explique :

① catégorie — c'est une chose / personne / endroit...
② fonction — ça sert à...
③ apparence — ça ressemble à...
④ contexte — on l'utilise quand...

🌸 STRUCTURES

🆕 -는 데 쓰다 — « servir à / être utilisé pour »

와인 열 때 쓰는 거예요. → C’est quelque chose qu’on utilise pour ouvrir le vin.

Cette structure devient un outil actif de paraphrase : quand le nom manque, explique à quoi la chose sert.

-는 데 쓰는 것
→ une chose utilisée pour...
-할 때 쓰는 것
→ quelque chose qu'on utilise quand...
-는 사람
→ une personne qui...
-는 곳
→ un endroit où...

💬 EXEMPLE

Mot inconnu : 우산 parapluie.

비 올 때 쓰는 거예요.
손으로 들고 다녀요.
비를 막아 줘요.

→ C'est quelque chose qu'on utilise quand il pleut.
→ On le tient à la main.
→ Ça évite d'être mouillé par la pluie.

💬 DIALOGUE

🌸 Ana : 그... 와인 열 때 쓰는 거 있잖아.
💚 Ji-soo : 와인 오프너?
🌸 Ana : 맞아! 그거!
💚 Ji-soo : 봐. 단어 몰라도 됐잖아ㅋㅋ

🧩 MISSION — MOT INTERDIT

Décris sans prononcer leur nom :

parapluie ; bibliothèque ; pharmacien ; chargeur ; ascenseur.

Ton partenaire doit deviner.

🌟 PHRASE

« Un mot inconnu n'est plus un mur : c'est simplement un détour. »
