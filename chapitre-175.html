Chapitre 175 · 🧩

Module 15 · Penser, paraphraser et improviser

Donner des exemples pour se faire comprendre

🎯 OBJECTIFS

✔ utiliser un exemple pour clarifier ;

✔ passer de l'abstrait au concret ;

✔ employer 예를 들면 / 예를 들어 / 같은 것 ;

✔ illustrer une opinion.

💙 EXEMPLES

예를 들면...
→ Par exemple...
예를 들어...
→ Par exemple...
커피나 차 같은 것
→ des choses comme le café ou le thé.
서울이나 부산 같은 큰 도시
→ de grandes villes comme Séoul ou Busan.

💬 DIALOGUE

💙 Min-su : 어떤 여행을 좋아해요?
🌸 Ana : 저는 너무 바쁜 여행은 별로 안 좋아해요. 예를 들면 하루에
관광지 다섯 군데씩 가는 여행이요.
💙 Min-su : 아, 천천히 여행하는 걸 좋아하는군요.
🌸 Ana : 맞아요.

L'exemple permet à Min-su de reformuler l'idée d'Ana.

🧩 MISSION

Explique une opinion abstraite puis ajoute : > exemple personnel ;
> contre-exemple ;
> situation concrète.

🌟 PHRASE

**« Quand une idée reste floue, un bon exemple peut faire le travail
de dix définitions. »**
