Chapitre 47 · 🤝

이것 좀 도와주세요.

Demander un service

🌸 Illustration d’ouverture

En quittant la boutique, Ana et Min-su passent devant une borne automatique.

Ana veut acheter un billet, mais quelque chose ne fonctionne pas.

🌸 Ana :
민수 씨, 이것 좀 도와주세요.

→ Min-su, aide-moi avec ça, s’il te plaît.

💙 Min-su :
네, 물론이죠.

→ Oui, bien sûr.

Ana connaissait déjà 주세요 pour demander un objet. Cette fois, elle demande à quelqu’un de faire une action pour elle.

🎯 Objectif

✅ demander à quelqu’un de faire quelque chose

✅ utiliser -아/어 주세요

✅ utiliser 좀 pour adoucir une demande

✅ demander de répéter, montrer, écrire ou vérifier

✅ reconnaître -아/어 줄 수 있어요? comme demande plus souple

✅ réutiliser les structures déjà connues dans des situations de voyage

🟩 Vocabulaire utile

도와주다 → aider

보여주다 → montrer

알려주다 → indiquer / faire savoir

설명하다 → expliquer

확인하다 → vérifier

기다리다 → attendre

열다 → ouvrir

닫다 → fermer

누르다 → appuyer

선택하다 → sélectionner

다시 → de nouveau

천천히 → lentement

이것 → ceci

좀 → un peu / adoucissement

물론 → bien sûr

💬 Dialogue

🌸 민수 씨, 이것 좀 도와주세요.
→ Min-su, aide-moi avec ça, s’il te plaît.

💙 네. 뭐가 어려워요?
→ Oui. Qu’est-ce qui est difficile ?

🌸 어떤 버튼이에요? 잘 모르겠어요.
→ C’est quel bouton ? Je ne sais pas trop.

💙 이 버튼을 누르세요.
→ Appuie sur ce bouton.

🌸 아, 네. 다시 한번 보여주세요.
→ Ah, d’accord. Montre-moi encore une fois, s’il te plaît.

💙 이렇게요.
→ Comme ça.

🌸 감사합니다. 그리고 이 문장도 설명해 주세요.
→ Merci. Et explique-moi aussi cette phrase, s’il te plaît.

💙 네. 다시 천천히 설명해요.
→ Oui. Je réexplique lentement.

🌸 이것도 확인해 주세요.
→ Vérifie aussi ça, s’il te plaît.

💙 물론이죠.
→ Bien sûr.

🌸 이제 혼자 할 수 있어요!
→ Maintenant, je peux le faire seule !

💙 Grammaire — -아/어 주세요

Pour demander poliment à quelqu’un de faire une action :

verbe + -아/어 주세요

도와주세요. → Aidez-moi, s’il vous plaît.

다시 말해 주세요. → Répétez, s’il vous plaît.

천천히 말해 주세요. → Parlez lentement, s’il vous plaît.

보여주세요. → Montrez-moi, s’il vous plaît.

확인해 주세요. → Vérifiez, s’il vous plaît.

🧩 Comment former -아/어 주세요 ?

On prend la forme en -아/어, puis on ajoute 주세요.

앉다 → 앉아 주세요
먹다 → 먹어 주세요
보여주다 → 보여 주세요
확인하다 → 확인해 주세요
설명하다 → 설명해 주세요

🟨 Pourquoi ?

Tu connaissais déjà :

커피 주세요. → Un café, s’il vous plaît.

Avec un nom, 주세요 signifie essentiellement « donnez-moi… ».

Avec un verbe en -아/어, -아/어 주세요 devient une demande polie pour que la personne réalise l’action.

💙 주다 — « donner » une action

주다 signifie « donner ».

보여주다 → montrer à quelqu’un

알려주다 → faire savoir / indiquer à quelqu’un

도와주다 → aider quelqu’un

🌸 좀 — un petit mot très important

이것 도와주세요. → Aidez-moi avec ça, s’il vous plaît.

이것 좀 도와주세요. → Pourriez-vous m’aider un peu avec ça ?

Dans une demande, 좀 sert souvent à rendre la phrase plus douce et naturelle.

이것 좀 봐 주세요. → Regardez ça, s’il vous plaît.

이것 좀 확인해 주세요. → Vérifiez ça, s’il vous plaît.

좀 천천히 말해 주세요. → Parlez un peu plus lentement, s’il vous plaît.

🌿 Demander de répéter

다시 말해 주세요. → Répétez, s’il vous plaît.

다시 한번 말해 주세요. → Dites-le encore une fois, s’il vous plaît.

한번 → une fois · 다시 한번 → encore une fois

🌸 Demander de parler plus lentement

천천히 말해 주세요. → Parlez lentement, s’il vous plaît.

좀 천천히 말해 주세요. → Parlez un peu plus lentement, s’il vous plaît.

💙 Demander de montrer

보여주세요. → Montrez-moi, s’il vous plaît.

이것 좀 보여주세요. → Montrez-moi ça, s’il vous plaît.

다시 보여주세요. → Montrez-moi encore une fois, s’il vous plaît.

천천히 보여주세요. → Montrez-moi lentement, s’il vous plaît.

🌸 Demander d’écrire

써 주세요. → Écrivez, s’il vous plaît.

여기 써 주세요. → Écrivez ici, s’il vous plaît.

주소를 써 주세요. → Écrivez l’adresse, s’il vous plaît.

💙 Demander de vérifier

확인해 주세요. → Vérifiez, s’il vous plaît.

예약을 확인해 주세요. → Vérifiez la réservation, s’il vous plaît.

이 주소를 확인해 주세요. → Vérifiez cette adresse, s’il vous plaît.

표를 확인해 주세요. → Vérifiez le billet, s’il vous plaît.

🌿 Pour aller plus loin — -아/어 줄 수 있어요?

Cette forme combine ce chapitre avec -(으)ㄹ 수 있어요 du chapitre 45.

도와줄 수 있어요? → Est-ce que tu pourrais m’aider ?

다시 말해 줄 수 있어요? → Est-ce que tu pourrais répéter ?

사진을 찍어 줄 수 있어요? → Est-ce que tu pourrais prendre une photo pour moi ?

🌸 Pour l’instant, retiens surtout -아/어 주세요. Tu rencontreras plus tard des façons encore plus respectueuses de formuler une demande.

🧠 Capacité · Permission · Service

사진을 찍을 수 있어요. → Je peux prendre une photo. Capacité

사진을 찍어도 돼요? → Est-ce que j’ai le droit de prendre une photo ? Permission

사진을 찍어 주세요. → Prenez une photo, s’il vous plaît. Demande

사진을 찍어 줄 수 있어요? → Pourriez-vous prendre une photo pour moi ? 🌿 Extension

📖 Compréhension

아나는 기차표를 사고 싶어요.

자동판매기가 어려워요.

아나는 직원에게 말해요.

“이것 좀 도와주세요.”

직원이 천천히 설명해요.

아나: 다시 한번 보여주세요.

직원: 네, 괜찮아요.

아나: 표도 확인해 주세요.

직원이 도와줘요.

이제 아나는 혼자 할 수 있어요.
