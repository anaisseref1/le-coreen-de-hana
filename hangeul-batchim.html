받침

Les batchim

Découvre la consonne finale qui se place en bas d'une syllabe.

🌿 Qu'est-ce qu'un 받침 ?

Un 받침 (batchim) est une consonne placée en bas d'un bloc syllabique.

Exemple :
한
Ici :

ㅎ = consonne initiale
ㅏ = voyelle
ㄴ = batchim

🧩 1. Ajouter une consonne finale

Nous avions vu :

ㅎ + ㅏ → 하

Si on ajoute ㄴ en bas :

ㅎ + ㅏ + ㄴ → 한

Le bloc contient toujours une seule syllabe, mais il possède maintenant une consonne finale.

🔊 2. Les sons finaux principaux

À l'écrit, de nombreuses consonnes peuvent apparaître en batchim.

À la prononciation, elles se regroupent autour d'un petit nombre de sons finaux principaux.

ㄱ / ㅋ / ㄲ → son final proche de k
ㄴ → son final n
ㄷ / ㅅ / ㅆ / ㅈ / ㅊ / ㅌ / ㅎ → son final proche de t
ㄹ → son final proche de l
ㅁ → son final m
ㅂ / ㅍ → son final proche de p
ㅇ → son final ng

🇰🇷 4. Exemple : 한국

Regarde le mot 한국 (« Corée »).

한
ㅎ + ㅏ + ㄴ
batchim : ㄴ
국
ㄱ + ㅜ + ㄱ
batchim : ㄱ

👀 5. Attention : l'écriture et le son

Toutes les consonnes finales ne gardent pas exactement leur son habituel.

Par exemple, plusieurs lettres différentes peuvent produire le même son final.

C'est normal.

Pour l'instant, retiens surtout les sept familles de sons :

ㄱ · ㄴ · ㄷ · ㄹ · ㅁ · ㅂ · ㅇ

Nous verrons ensuite ce qui se passe lorsqu'une nouvelle syllabe commence après un batchim.
💙 Astuce pour lire

Quand tu vois un bloc coréen, regarde-le dans cet ordre :

1. consonne initiale
2. voyelle
3. consonne éventuelle en bas

Exemple :

밥 = ㅂ + ㅏ + ㅂ

Tu n'as pas besoin de lire toutes les lettres séparément à voix haute : le but est progressivement de reconnaître le bloc comme une syllabe complète.
