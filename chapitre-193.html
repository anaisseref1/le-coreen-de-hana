Chapitre 193 · 🔎

Module 16 · Je n’ai plus besoin du manuel

Apprendre seule à partir d’un contenu authentique

🌸 Illustration d'ouverture

Pendant quinze modules, le manuel a choisi :

les mots ;
les exemples ;
les audios ;
les exercices.

Aujourd'hui :

직접 골라 보세요.

Choisis toi-même.

🎯 OBJECTIFS

✔ sélectionner un contenu adapté ;

✔ extraire ce qui est utile ;

✔ ne pas apprendre tous les mots ;

✔ créer ses propres exemples ;

✔ revoir ce qui mérite réellement d'être retenu.

💙 CHOISIS

une vidéo ;
un podcast ;
une publication ;
un article ;
une scène ;
une interview ;
un commentaire ;
un sujet qui t'intéresse.

🌸 MÉTHODE

1. 전체 내용

Comprends l'ensemble.

2. 중요한 표현

Choisis 3 à 5 expressions maximum.

3. 문맥

Observe comment elles sont utilisées.

4. 내 문장

Crée tes propres phrases.

5. 다시 만나기

Reviens-y quelques jours plus tard.

🟨 NE COLLECTIONNE PAS LES MOTS

Un carnet rempli de 300 mots jamais réutilisés n'est pas nécessairement
un bon apprentissage.

Privilégie :

fréquence + utilité + intérêt personnel + réemploi.

🧩 MISSION — TON PREMIER MINI-COURS

À partir d'un contenu authentique, crée toi-même :

résumé ;
5 expressions ;
3 questions ;
mini-exercice ;
production personnelle.

Tu deviens temporairement l'autrice de ton propre chapitre.

🌟 PHRASE

혼자 공부할 수 있게 되는 것이 이 교재의 진짜 목표예요.

🎧 Prononciation / écoute
