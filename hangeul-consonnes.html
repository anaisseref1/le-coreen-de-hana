Les consonnes

Découvre les consonnes du Hangeul et familiarise-toi avec leur son.

🌿 Avant de commencer

Le Hangeul possède 14 consonnes de base.

Certaines consonnes ont aussi une version tendue, comme ㄲ ou ㅆ.

Les sons indiqués ici sont des repères pour débuter. En coréen, une consonne peut sonner légèrement différemment selon sa position dans le mot. Nous verrons ces changements plus tard.

🔤 1. Les 14 consonnes de base

Appuie sur « Écouter » pour entendre une syllabe simple contenant la consonne. Une consonne seule n'est généralement pas prononcée naturellement, donc nous l'écoutons avec la voyelle ㅏ.

💨 2. Consonnes aspirées

Certaines consonnes sont prononcées avec une sortie d'air plus forte.

ㅋ → k aspiré
ㅌ → t aspiré
ㅍ → p aspiré
ㅊ → tch aspiré

Compare par exemple 가 et 카 : le deuxième son laisse passer davantage d'air.

💥 3. Consonnes tendues

Le Hangeul possède aussi cinq consonnes doubles dites « tendues ». Elles sont prononcées avec davantage de tension, mais sans forte aspiration.

ㄲ → kk
ㄸ → tt
ㅃ → pp
ㅆ → ss
ㅉ → jj

💙 Ne cherche pas encore la perfection

Pour l'instant, l'objectif est surtout de reconnaître les formes et de commencer à distinguer les familles de sons.

Les différences entre ㄱ / ㅋ / ㄲ, ㄷ / ㅌ / ㄸ, ㅂ / ㅍ / ㅃ ou ㅅ / ㅆ deviennent beaucoup plus claires avec l'écoute et la pratique.
