🧠 Grammaire essentielle

날씨가 어때요?
날씨 = la météo
어때요? = comment est... ?

→ « Quel temps fait-il ? »
조금
Signifie « un peu ».

조금 더워요. → Il fait un peu chaud.
조금 추워요. → Il fait un peu froid.
-(으)ㄹ 것 같아요
Sert à exprimer une impression ou une prévision : « Je pense que... / On dirait que... »

비가 올 것 같아요. → Je pense qu'il va pleuvoir.

좋을 것 같아요. → Je pense que ce sera bien.

맛있을 것 같아요. → Ça a l'air bon.
비가 와요 ≠ 비가 올 것 같아요
비가 와요. → on constate qu'il pleut.

비가 올 것 같아요. → on exprime une impression ou une prévision.
날씨
Le double ㅆ se prononce comme un s bien marqué.

Prononciation : nal-ssi.
