Chapitre 110 · 🧩

Prévu → réalité → conséquence → besoin

Expliquer précisément un problème

🧩 Illustration

Dire 문제가 있어요 ne suffit plus. Ana apprend à donner les informations qui permettent réellement à l’autre personne de résoudre le problème.

🎯 Objectifs

✅ expliquer ce qui était prévu
✅ dire ce qui s’est réellement passé
✅ montrer la conséquence
✅ formuler clairement le besoin

1️⃣ Ce qui devait arriver

어제 주문했어요. → J’ai commandé hier.
방을 예약했어요. → J’ai réservé une chambre.

2️⃣ Ce qui s’est passé

그런데 다른 상품이 왔어요. → Mais un autre produit est arrivé.
제가 예약한 방이 아닌 것 같아요. → Je crois que ce n’est pas la chambre réservée.

3️⃣ Conséquence

방에 들어갈 수 없어요. → Je ne peux pas entrer dans la chambre.
오늘 필요해요. → J’en ai besoin aujourd’hui.

4️⃣ Besoin

확인해 주실 수 있어요? → Pourriez-vous vérifier ?
변경할 수 있어요? → Est-ce qu’on peut modifier ?

🧠 Formule

prévu → réalité → conséquence → besoin. Une bonne explication pratique aide l’autre personne à savoir quoi vérifier.

🌟 Idée centrale

Être précise ne signifie pas parler longtemps : cela signifie donner les bonnes informations dans le bon ordre.
