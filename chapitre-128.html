Chapitre 128 · 💬

Module 12 · Rapporter les paroles et les points de vue

Consolider « il/elle a dit que… »

🌸 Illustration d'ouverture

💙 Min-su : 지수 씨가 뭐라고 했어요?
Qu'est-ce que Ji-soo a dit ?

🌸 Ana : 피곤하다고 했어요.
Elle a dit qu'elle était fatiguée.

Ana connaît la base. Mais comment rapporter le passé, le futur ou une
phrase avec un nom ?

🎯 OBJECTIFS

✔ consolider -다고 하다 ; ✔ rapporter présent, passé et futur ; ✔
distinguer verbes d'action, verbes descriptifs et noms ; ✔ identifier
clairement le locuteur.

💙 DÉCLARATION RAPPORTÉE

Action : → 가요 → 간다고 했어요.
→ Il/elle a dit qu'il/elle allait.

먹어요 → 먹는다고 했어요.
→ Il/elle a dit qu'il/elle mangeait.

Description : → 피곤해요 → 피곤하다고 했어요.
→ Elle a dit qu'elle était fatiguée.

Nom : → 학생이에요 → 학생이라고 했어요.
→ Elle a dit qu'elle était étudiante.

🌸 PASSÉ ET FUTUR

부산에 갔어요 → 부산에 갔다고 했어요.
→ Elle a dit qu'elle était allée à Busan.
내일 갈 거예요 → 내일 갈 거라고 했어요.
→ Elle a dit qu'elle irait demain.

💬 DIALOGUE

💙 Min-su : 지수 씨 주말에 뭐 했어요?
🌸 Ana : 부산에 갔다고 했어요. 친구랑 같이 갔다고 했어요.
💙 Min-su : 다음 여행 계획도 있어요?
🌸 Ana : 다음에는 제주도에 갈 거라고 했어요.

🟨 ATTENTION

Dans une phrase rapportée, demande-toi toujours : qui parle ? de qui
parle-t-on ?
