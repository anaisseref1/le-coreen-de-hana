Module 2 · Chapitre 16

🏨 호텔에서 체크인하기

Résumé

Arriver à l'hôtel, demander les informations essentielles et demander de l'aide.

🎯 Objectif

Savoir annoncer une réservation, répondre quand le personnel demande ton nom, demander où est ta chambre, demander le mot de passe du Wi-Fi, signaler un problème et demander de l'aide.

🏨 Vocabulaire essentiel

호텔 → hôtel

방 → chambre

열쇠 → clé

예약 → réservation

성함 → nom — forme respectueuse

와이파이 → Wi-Fi

비밀번호 → mot de passe

도와주세요 → Aidez-moi, s'il vous plaît.

감사합니다 → merci

🧩 Structures importantes

예약했어요.
→ J'ai une réservation. / J'ai réservé.

N이/가 어디예요?
제 방이 어디예요? → Où est ma chambre ?

N이/가 뭐예요?
와이파이 비밀번호가 뭐예요? → Quel est le mot de passe du Wi-Fi ?

안 돼요
와이파이가 안 돼요. → Le Wi-Fi ne fonctionne pas.

도와주세요.
→ Aidez-moi, s'il vous plaît.

💬 Phrases à retenir

예약했어요.

성함이 어떻게 되세요?

하나예요.

제 방이 어디예요?

방 열쇠 주세요.

와이파이 비밀번호가 뭐예요?

와이파이가 안 돼요.

도와주세요.

감사합니다.

🌿 Récapitulatif

Tu sais maintenant gérer les échanges essentiels à ton arrivée dans un hôtel coréen : réservation, nom, chambre, Wi-Fi et demande d'aide.
