Module 16 · Je n’ai plus besoin du manuel

Projet final : vivre une situation réelle de A à Z

🎯 OBJECTIF

Accomplir un projet complet en utilisant le coréen comme outil.

🌸 CHOISIS UN PROJET

✈️ PROJET A — ORGANISER UN VOYAGE

Tu dois :

rechercher une destination ;
comparer ;
lire des avis ;
construire un programme ;
expliquer tes choix ;
résoudre un imprévu.

🎥 PROJET B — PRÉSENTER UN CONTENU

Choisis un sujet.

recherche → notes → présentation → questions → discussion.

👥 PROJET C — ORGANISER UNE SORTIE

proposer ;
négocier date et lieu ;
comprendre les préférences ;
réserver ou simuler ;
gérer un changement.

📚 PROJET D — APPRENDRE QUELQUE CHOSE EN CORÉEN

Choisis un sujet que tu ne connais pas.

Utilise des ressources coréennes.

Puis enseigne ce que tu as appris.

😈 CONDITION

Le projet doit produire quelque chose de concret :

programme ;
présentation ;
décision ;
résumé ;
guide ;
conversation.

📓 JOURNAL

Pendant le projet, note seulement :

막힌 것
해결한 방법
새로 배운 것
다음에 더 잘하고 싶은 것

🌟 PHRASE

한국어를 배우는 프로젝트가 아니라 한국어로 하는 프로젝트예요.
