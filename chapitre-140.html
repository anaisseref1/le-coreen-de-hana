Module 12 · Rapporter les paroles et les points de vue

Rapporter les paroles et les points de vue sans script

🌸 Illustration d'ouverture

Ana reçoit trois enregistrements : Ji-soo raconte un problème, Min-su
donne son opinion, Su-jin rapporte les paroles d'une autre personne.

Une instruction :

무슨 이야기예요? 설명해 보세요.
Explique de quoi il s'agit.

Bienvenue au boss final. 😈

🎯 OBJECTIF FINAL

✔ déclarations ; ✔ questions ; ✔ consignes ; ✔ propositions ; ✔
contractions ; ✔ sources ; ✔ rumeurs ; ✔ comparaison ; ✔ résumé ; ✔
correction d'une information déformée.

🏆 MISSION 1 — QUI A DIT QUOI ?

Écoute une conversation à quatre personnes et rapporte : → A a dit
que...
→ B a demandé si...
→ C a proposé de...
→ D a demandé à quelqu'un de...

😈 MISSION 2 — LA SOURCE DISPARAÎT

Phrase : → 내일 문을 닫는대요.

Réponds : 1. Qui l'a dit ? 2. Est-ce certain ? 3. Comment demander la
source ? 4. Comment reformuler si l'information vient seulement d'un
commentaire en ligne ?

😈 MISSION 3 — TROIS PERSONNES, TROIS AVIS

Sujet : 외국에서 1년 동안 사는 것.

Donne le point commun, les différences, les raisons principales et ton
propre avis.

🚨 MISSION 4 — INFORMATION DÉFORMÉE

Interviens avec : → 그런 뜻이 아니었어요.
→ 제가 말한 건...
→ 정확히 말하면...

🎧 MISSION 5 — RÉSUMÉ FINAL

Après une discussion : → 무슨 얘기였어요?
→ 누가 어떤 의견이었어요?
→ 왜 그렇게 생각했어요?
→ 결론이 있었어요?
→ 확실하지 않은 정보가 있었어요?

Toujours aucune catégorie « grammaire parfaite ».

Une terminaison imparfaite se corrige. Confondre « il a proposé de
venir » et « il a ordonné de venir » change le message : la
priorité est la fidélité communicative.

💚 LE CONSEIL DE JI-SOO

들은 말을 그대로 믿지 마. 먼저 누가 말했어? 확인해 봐.

→ Avant de croire directement ce que tu as entendu, vérifie qui l'a dit.

🌟 PHRASE FINALE DU MODULE 12

« Rapporter les paroles de quelqu'un, ce n'est pas parler à sa place
: c'est transmettre son message sans en changer la voix. »
