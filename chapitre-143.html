Chapitre 143 · 📰

Module 13 · Médias et numérique

Comprendre les titres et miniatures

🌸 Illustration d'ouverture

Ana voit :

한국에서 꼭 먹어 봐야 할 음식 5가지

Puis :

서울 직장인의 현실적인 하루

Puis :

드디어 공개!

Où sont les phrases complètes ? 😭

🎯 OBJECTIFS

✔ comprendre qu'un titre peut supprimer des éléments grammaticaux ;

✔ reconnaître les mots-clés ;

✔ interpréter les formulations fréquentes des titres ;

✔ distinguer titre informatif et titre destiné à attirer l'attention.

🟩 VOCABULAIRE

추천 → recommandation
후기 → retour / avis
리뷰 → review
공개 → révélation / publication
필수 → indispensable
꿀팁 → astuce très utile
총정리 → récapitulatif complet
비교 → comparaison
현실 → réalité
직접 → directement / soi-même
솔직 → franc / honnête

💙 TITRE ≠ PHRASE SCOLAIRE

제주도 여행 후기

Littéralement :

Jeju + voyage + retour d'expérience

Naturellement :

Mon retour sur mon voyage à Jeju.

🌸 꼭 + -아/어야 하다 — RÉEMPLOI D’UNE STRUCTURE CONNUE

꼭 먹어 봐야 할 음식

→ les plats qu'il faut absolument essayer.

😈 TITRES ACCROCHEURS

진짜 가능할까?
→ Est-ce vraiment possible ?
결국 샀습니다
→ J'ai finalement acheté...
절대 하지 마세요
→ Ne faites surtout pas ça.

Comprendre le titre ne signifie pas encore croire sa promesse.

🧩 MISSION --- 10 TITRES

Pour chaque titre :

  1. sujet ;
  2. type de contenu ;
  3. promesse implicite ;
  4. phrase complète probable.

🌟 PHRASE

**« Un titre ne te donne pas toujours une phrase ; il te donne
suffisamment d'indices pour reconstruire son intention. »**
