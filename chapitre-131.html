Module 12 · Rapporter les paroles et les points de vue

Rapporter une proposition

🎯 OBJECTIFS

✔ utiliser -자고 하다 ; ✔ rapporter « faisons... » ; ✔ distinguer
proposition et ordre.

💙 PROPOSITION

같이 가요. → 같이 가자고 했어요.
→ Il/elle a proposé qu'on y aille ensemble.
영화 봐요. → 영화 보자고 했어요.
→ Il/elle a proposé qu'on regarde un film.

💬 DIALOGUE

💙 Min-su : 주말 계획 정했어요?
🌸 Ana : 네. 지수가 토요일에 같이 영화 보자고 했어요. 저녁도 같이
먹자고 했어요.
💙 Min-su : 재미있을 것 같아요.

🧠 COMPARONS

가라고 했어요. → Il/elle a dit à quelqu'un d'y aller.
가자고 했어요. → Il/elle a proposé d'y aller ensemble.

✍️ EXERCICES

Rapporte : 같이 공부해요 / 주말에 여행 가요 / 저녁 먹어요 / 카페에서
만나요.

🧩 MISSION

Écoute une discussion et note : personne → proposition → réponse.

🌟 PHRASE

**« Une proposition rapportée raconte aussi comment une décision
collective a commencé. »**
