Module 12 · Rapporter les paroles et les points de vue

Rapporter une question

🌸 Illustration d'ouverture

Ji-soo dit : → 민수가 주말에 뭐 하냐고 물어봤어.

Ana reconnaît tous les mots... sauf 하냐고. 😭

🎯 OBJECTIFS

✔ rapporter une question avec -(느)냐고 하다 / 물어보다 ; ✔
rapporter une question ouverte ; ✔ rapporter une question oui/non.
💡 On apprend surtout les formes courantes -냐고 / -느냐고 sans transformer le chapitre en tableau de conjugaison.

💙 QUESTION RAPPORTÉE

어디에 가요? → 어디에 가냐고 물어봤어요.
→ Il/elle a demandé où j'allais.
뭐 먹어요? → 뭐 먹냐고 물어봤어요.
→ Il/elle a demandé ce que je mangeais.
괜찮아요? → 괜찮냐고 물어봤어요.
→ Il/elle a demandé si ça allait.
학생이에요? → 학생이냐고 물어봤어요.
→ Il/elle a demandé si j'étais étudiant(e).

💬 DIALOGUE

💚 Ji-soo : 아까 민수가 너 어디 갔냐고 물어봤어.
🌸 Ana : 진짜?
💚 Ji-soo : 응. 몇 시에 올 거냐고도 물어봤어.
🌸 Ana : 아, 내가 연락할게.

🟨 POURQUOI ?

Une question rapportée doit conserver l'intention de demander, pas
la terminaison polie de la question originale.

✍️ EXERCICES

Rapporte : 어디에 살아요? / 언제 와요? / 커피 좋아해요? / 학생이에요?

🧩 MISSION

Écoute cinq questions posées à Min-su puis explique ce qu'on lui a
demandé.

🌟 PHRASE

« Rapporter une question, c'est conserver l'intention de demander.
»
