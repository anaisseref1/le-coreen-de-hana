Module 15 · Penser, paraphraser et improviser

Conversation réelle : je ne connais pas le mot, mais je continue

🌸 Illustration d'ouverture

Ana raconte son week-end à Ji-soo et Min-su.

Elle veut parler d'un objet acheté dans un marché.

Le mot disparaît.

Ancienne Ana :

téléphone.

Nouvelle Ana :

😈 Pas besoin.

💬 CONVERSATION

🌸 Ana : 어제 시장에서 되게 예쁜 걸 샀어. 이름이 뭐지... 그...
집에서 좋은 향이 날 때 쓰는 거. 불을 켜는 건 아니고...
💚 Ji-soo : 디퓨저?
🌸 Ana : 맞아! 디퓨저. 작은 병인데 냄새가 진짜 좋아.
💙 Min-su : 무슨 향이에요?
🌸 Ana : 그것도 이름을 모르겠는데ㅋㅋ 약간 달고... 여름에 바닷가에서
맡을 것 같은 향?
💚 Ji-soo : 코코넛 같은 거?
🌸 Ana : 아! 맞아, 코코넛 비슷해.

La conversation n'a jamais cessé.

🎯 OBJECTIFS

✔ combiner toutes les stratégies ;

✔ accepter l'aide de l'interlocuteur ;

✔ préciser progressivement ;

✔ continuer après avoir retrouvé le mot.

🧠 STRATÉGIES UTILISÉES

Ana :

signale le trou lexical ;
donne la fonction ;
décrit ;
accepte une proposition ;
reprend immédiatement son récit.

Le mot inconnu n'a occupé que quelques secondes.
