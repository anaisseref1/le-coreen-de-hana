Module 13 · Médias et numérique

Comprendre les abréviations et le coréen raccourci

🌸 Illustration d'ouverture

Ana reçoit :

ㄱㄱ?

Elle regarde Ji-soo.

🌸 Ana : ...C'est une faute de frappe ?

💚 Ji-soo : ㅋㅋㅋ 아니.

🎯 OBJECTIFS

✔ reconnaître le principe des abréviations consonantiques ;

✔ comprendre quelques formes très fréquentes ;

✔ utiliser le contexte plutôt qu'une liste infinie ;

✔ distinguer compréhension passive et production.

🟩 EXEMPLES FRÉQUENTS

ㄱㄱ → 고고 → go go / on y va
ㅇㅇ → 응응 → oui / ouais
ㄴㄴ → 노노 → non / nope
ㅊㅋ → 축하 → félicitations
ㄱㅅ → 감사 → merci
ㅈㅅ → 죄송 → désolé
ㄹㅇ → 리얼 → vraiment / pour de vrai

⚠️ Les usages changent selon les générations, communautés et
plateformes.

💙 MÉTHODE DE DÉCODAGE

Si tu rencontres une abréviation inconnue :

  1. regarde la phrase autour ;
  2. identifie la réaction attendue ;
  3. cherche si les consonnes peuvent correspondre à un mot connu ;
  4. ne l'utilise pas avant d'avoir compris son registre.

💬 CHAT

💚 Ji-soo : 오늘 저녁 영화 ㄱㄱ?
🌸 Ana : ㅇㅇㅋㅋ 몇 시?
💚 Ji-soo : 8시 어때?
🌸 Ana : 좋아!

🧩 MISSION --- DÉCODE, MAIS N'INVENTE PAS

Décoder dix messages. Pour une abréviation inconnue, Ana doit dire :

잘 모르겠어. 이게 무슨 뜻이야?
→ Je ne sais pas trop. Ça veut dire quoi ?

🌟 PHRASE

**« Le but n'est pas de mémoriser tout Internet : c'est de savoir quoi
faire quand Internet invente encore quelque chose. »**
