Chapitre 195 · 🌱

Module 16 · Je n’ai plus besoin du manuel

Construire son propre coréen

🌸 Illustration d'ouverture

Ana regarde son carnet.

Elle connaît des centaines de mots.

Mais certains lui ressemblent davantage.

Elle parle souvent de :

voyages ;
personnes qu'elle aime ;
nourriture ;
travail ;
projets ;
émotions ;
musique ;
expériences.

Son coréen commence à avoir une identité.

🎯 OBJECTIFS

✔ identifier son vocabulaire personnel ;

✔ construire ses domaines prioritaires ;

✔ développer des expressions réellement utiles ;

✔ accepter que deux apprenants n'aient pas exactement le même coréen.

💙 TON VOCABULAIRE ACTIF

Crée six catégories :

내 일상
내 사람들
내가 좋아하는 것
내 일 / 공부
내 생각
내 미래

Dans chaque catégorie :

mots que j'utilise ;
expressions que je veux automatiser ;
sujets que je veux pouvoir développer.

🌸 TON « KIT DE PAROLE »

Choisis tes expressions naturelles pour :

hésiter ;
être d'accord ;
nuancer ;
raconter ;
reformuler ;
réagir ;
relancer.

Pas besoin d'utiliser toutes les expressions du manuel.

Construis les tiennes.

🧩 MISSION — QUI SUIS-JE EN CORÉEN ?

Parle dix minutes de toi sans suivre une fiche d'identité scolaire.

Pas :

Je m'appelle... j'ai... j'habite...

Mais :

ce qui compte pour toi ;
ce qui t'intéresse ;
ce qui a changé ;
ce que tu veux faire ;
ce que tu penses.

🌟 PHRASE

언어를 오래 쓰면 그 언어 안에서도 자기다운 말투가 생겨요.
